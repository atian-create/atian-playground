# 阿甜的 Skill 游乐园

[English](README_EN.md) · 简体中文

把阿甜真实做过的开源 Skill、网站和互动项目，变成一座可以逛、可以点击、可以直接复制给 Agent 使用的连续三维乐园。

在线游园：[阿甜的 Skill 游乐园](https://atian-create.github.io/atian-playground/)

![三维乐园真实页面截图](docs/screenshots/park-3d-overview.png)

四区共用同一个三维场景和道路网络。选择园区时镜头平滑移动，游客与设施继续运行。拖动转动视角，滚轮或加减按钮缩放，点击建筑任意主体区域查看项目。

## 它能做什么

- 收录 48 个已经公开的 GitHub 项目。
- 在同一座乐园里游览四种环境：「北园区 · 创作花园街 / 东园区 · 媒体嘉年华 / 西园区 · 知识森林 / 南园区 · 湖畔游戏岛」。
- 48 座三维设施对应 48 个真实项目；整座建筑可以点击，鼠标悬停时出现环绕粒子。
- 每个项目提供 GitHub 入口、按用途准备输入的教程、中英文操作指南、项目专属提示词与已有仓库预览。
- 58 位立体游客有双腿交替、屈膝、摆臂、身体起伏与路口转向。人物与设施使用同一场景的光照、深度遮挡和道路。
- 摩天轮座舱保持水平；过山车沿三维轨道运行；木马上下起伏；摆锤、船、火车和气球各自运动。
- 提供项目搜索、动画暂停、减少动态效果支持和 WebGL 不可用时的项目目录。
- “待补内容”展示公开仓库收录和文档检查结果。检查为静态证据，不代表已运行所有第三方项目。

## 使用图解

1. 点击园区名称，或在左侧搜索一个项目。
2. 点击场景中的建筑或项目名称，阅读输入准备说明。
3. 点击“复制这个项目的启动提示词”，粘贴到你的 Agent 中。也可以直接打开 GitHub。
4. 点击“在园内找到它”，镜头会定位到对应设施。

## 核对项目收录

```bash
node scripts/audit-catalog.mjs
```

需要已登录的 GitHub CLI。该脚本仅检查 atian-create 的公开非 fork 仓库，生成 `src/data/catalog-audit.json`。2026-09-05 核对 48/48 已收录；26 个 README 未嵌图，34 个英文说明待人工核对。仅按文件名和常见章节识别英文文档，不能据此断言仓库完全没有英文内容。

## 模型与运行边界

三维设施和人物由 Three.js 程序生成，风格参考游乐园经营游戏。仓库没有导入原版《过山车》游戏的完整模型；人物步态是关节程序动画，不是动作捕捉。当前不包含排队乘坐、模拟经营、游客间避让或原游戏存档导入。WebGL2 无法使用时仍可从目录访问全部项目。

## 本地运行

```bash
npm install
npm run dev
```

生成无需服务器的本地单文件：

```bash
npm run build:local
```

然后直接打开 `阿甜游乐园.html`。

## 复制给 Agent

```text
请阅读并运行这个项目：https://github.com/atian-create/atian-playground
先查看 README 和项目结构，然后告诉我如何新增一个真实项目、把它映射成相关娱乐设施，并完成本地构建验证。
```

## 项目原则

- 只展示真实完成或已经公开的项目。
- 设施隐喻必须与项目能力相关。
- 中文标题由网页代码渲染，避免生成图片文字乱码。
- 不读取或上传本地私人资料。
